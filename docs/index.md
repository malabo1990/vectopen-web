# Vectopen

**Vectopen** is a free, open-source vector graphics editor for Windows, macOS and Linux, built with [Godot Engine](https://godotengine.org). No account, no telemetry, no paid tier.

This is the **user manual**: how to install Vectopen, how the three interfaces are laid out, what each tool and panel does, and how to save, export and automate your work.

!!! info "Current version: 0.2.0-alpha"
    This is an **alpha**: most things work, some don't yet, and you will find bugs. Each page says plainly when something is incomplete. If something breaks, please tell us on **[Telegram](https://t.me/vectopen)** or open an issue on **[GitHub](https://github.com/malabo1990/-Vectopen/issues)**.

## What's new in 0.2.0-alpha

- First downloadable builds: Windows, macOS (Intel + Apple Silicon) and Linux (.deb, .rpm, .tar.gz).
- Three interfaces — **Smart**, **Modern** and **Pro** — each with the full set of panels.
- Gradients on **strokes**, not only fills.
- A shape library: heart, drop, arrows, cross, moon, bolt, speech bubble, cloud.
- Layers with type icons, thumbnails, a compact view and correct sub-layers.
- **Vectorize images** with two offline AI tools: background removal and ×4 upscaling (Linux).
- 10 interface languages.
