# Vectopen

**Vectopen** is a free, open-source vector graphics editor for Windows, macOS, Linux and Android (preview), built with [Godot Engine](https://godotengine.org). No account, no telemetry, no paid tier.

This is the **user manual**: how to install Vectopen, how the three interfaces are laid out, what each tool and panel does, and how to save, export and automate your work.

!!! info "Current version: 0.2.4-beta"
    This is a **beta**: most things work, some don't yet, and you will find bugs. Each page says plainly when something is incomplete. If something breaks, please tell us on **[Reddit](https://www.reddit.com/r/Vectopen_editor/)**, **[Telegram](https://t.me/vectopen)** or open an issue on **[GitHub](https://github.com/malabo1990/-Vectopen/issues)**.

## What's new in 0.2.4-beta

- **[2D lighting](objects/lighting.md)** with real-time shadows (point, spot, sun and ambient).
- **[Blends](objects/blend.md)** between two or more objects, gradients too, optionally along a guide.
- **[Real tables](objects/layout.md#tables)** with their own panel, flex and grid **containers**, linked **components** and **master pages**.
- **[Advanced corners](tools/shapes.md#advanced-corners)** and **[Convert to Bézier path](tools/shapes.md#convert-to-bezier-path)**.
- Live **Shift + drag stroke width** with the brush and over shapes and paths.
- **[Vectorize](objects/vectorize.md)** now on Windows and Apple Silicon Macs too; a **[Windows installer](getting-started/installation.md#windows-10-11-64-bit)** and automatic updates.
- Clicking and releasing shapes is faster than ever.
