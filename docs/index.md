# Vectopen

**Vectopen** is a free, open-source vector graphics editor built with [Godot Engine](https://godotengine.org) 4.7 — think Figma/Illustrator, running on Godot's own 2D engine.

This site is the **user manual**: how to install Vectopen, how the interface is laid out, what each tool does, how projects are saved and exported, and how to connect an AI agent to a running instance through the built-in MCP server.

!!! note "Looking for the source code?"
    Vectopen lives at [github.com/malabo1990/-Vectopen](https://github.com/malabo1990/-Vectopen). Architecture notes, benchmarks, and other developer-facing material live under `docs/` in the repository itself — this site only covers *using* the app.

## Where to start

- New here? Start with **[Installation](getting-started/installation.md)** and **[Quick Start](getting-started/quick-start.md)**.
- Already have it running? Jump to **[The Interface](getting-started/interface.md)** for a tour, or straight to **[Tools](tools/index.md)**.
- Want an AI agent to drive the canvas for you? See **[MCP Server](integrations/mcp-server.md)**.

## Status

Vectopen is under active development. Some panels and shortcuts described here may be partially implemented — each page tries to say plainly when a feature is still incomplete rather than describe aspirational behavior.
