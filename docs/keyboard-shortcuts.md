# Keyboard Shortcuts

These are the shortcuts currently wired to real behavior in Vectopen.

## Editing

| Action | Shortcut |
|---|---|
| Undo | Ctrl+Z |
| Redo | Ctrl+Shift+Z |
| Delete selection | Delete or Backspace |
| Copy | Ctrl+C |
| Cut | Ctrl+X |
| Paste | Ctrl+V |
| Duplicate | Ctrl+D |
| Select All | Ctrl+A |

## View

| Action | Shortcut |
|---|---|
| Pan canvas | Space + drag, or middle-click + drag |
| Zoom in | Ctrl+= |
| Zoom out | Ctrl+- |
| Reset zoom to 100% | 5 |
| Zoom under cursor | Scroll wheel |

## Text tool

| Action | Shortcut |
|---|---|
| Scale font size | Ctrl/Cmd + drag vertically on a text block |

!!! note "Not a fixed keymap yet"
    Vectopen doesn't currently expose a settings UI for rebinding these — the list above reflects the app's built-in defaults.
