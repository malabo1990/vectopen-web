# Keyboard Shortcuts

The default shortcuts. Single-letter shortcuts only work when you're not typing in a text field. On macOS, **Ctrl** means **Cmd**.

The **keyboard panel** (keyboard button at the bottom-left in Smart) lists the configurable actions; search for one, click it and press the new key.

## Tools

| Tool | Key |
|---|---|
| Select | V |
| Rectangle | R |
| Ellipse | E |
| Star | S |
| Bézier | D |
| Brush | B |
| Text | T |
| Paragraph text | P |
| Artboard | A |
| Hand (pan) | W |

## File & edit

| Action | Shortcut |
|---|---|
| New document | Ctrl+N |
| Save | Ctrl+S |
| Undo / Redo | Ctrl+Z / Ctrl+Shift+Z |
| Copy / Cut / Paste | Ctrl+C / Ctrl+X / Ctrl+V |
| Duplicate | Ctrl+D |
| Select all | Ctrl+A |
| Delete | Delete, Backspace or X |
| Nudge the selection | Arrow keys |
| Group / Ungroup | Ctrl+G / Ctrl+Shift+G |

## With objects selected

| Action | Shortcut |
|---|---|
| Opacity 10 % … 90 % | 1 … 9 |
| Opacity 100 % | 0 |
| Exact opacity (e.g. 45 %) | Two digits quickly: 4 then 5 |
| Move / Rotate / Scale with the mouse | Shift+G / Shift+R / Shift+S — then X or Y to lock an axis, click to confirm, Escape to cancel |
| Gradient mode on the canvas | G (V or Escape to leave) |
| Text weight heavier / lighter | Ctrl+Alt+. / Ctrl+Alt+, |
| Cancel a drag in progress | Escape |

## Node editing

| Action | Shortcut |
|---|---|
| Select all points | A |
| Delete points | X, Delete or Backspace |
| Grab (move) points | G, then X / Y to lock an axis; Enter or click to confirm, Escape to cancel |
| Back to Select | Escape |

## View

| Action | Shortcut |
|---|---|
| Pan | Space + drag, middle-button drag, or the Hand tool |
| Zoom | Scroll wheel (under the cursor) · Ctrl+= / Ctrl+- |
| Zoom by dragging | Hold Z and drag |
| Reset zoom (100 %) | 5 |
| Scroll a panel | Middle-button drag over the inspector or Layers |

Shortcuts keep working when the mouse is over a panel, as long as you're not typing in a text field.
