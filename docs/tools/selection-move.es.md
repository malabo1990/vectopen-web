# Selección y mover

## Herramienta de selección

La herramienta por defecto para trabajar con figuras existentes.

- **Clic** en una figura para seleccionarla. Clic en espacio vacío para vaciar la selección.
- **Clic y arrastra** una figura seleccionada para moverla.
- **Arrastra un asa** de esquina o borde para redimensionarla.
- **Shift+clic** para añadir/quitar una figura de la selección actual (multiselección).
- La selección aquí es la misma que se muestra en el **panel de capas** y se edita en el **Inspector** — los tres se mantienen sincronizados.

Con una selección activa, aplican los atajos de edición estándar:

| Acción | Atajo |
|---|---|
| Borrar | Delete / Backspace |
| Copiar | Ctrl+C |
| Cortar | Ctrl+X |
| Pegar | Ctrl+V |
| Duplicar | Ctrl+D |
| Seleccionar todo | Ctrl+A |

Ver **[Atajos de teclado](../keyboard-shortcuts.md)** para la lista completa.

## Herramientas Mover y Mano

Por ahora, los botones de barra **Mover** y **Mano** ejecutan la misma implementación que **Selección** — todo lo de arriba aplica también a ellas. Un comportamiento distinto (mover el artboard con Mover, navegación pura con Mano) está planeado pero aún no implementado. Para navegar el lienzo ahora mismo, ver **[Mano y navegación](hand-navigation.md)** — no depende de qué herramienta esté activa.
