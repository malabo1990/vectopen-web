# Selección

La herramienta **Selección** (**V**) es la herramienta por defecto para trabajar con objetos.

- **Haz clic** en un objeto para seleccionarlo; clic en un espacio vacío para deseleccionar.
- **Mayús+clic** añade o quita objetos de la selección. Arrastra en un espacio vacío para seleccionar con un recuadro.
- **Arrastra** un objeto seleccionado para moverlo. Mantén **Mayús** para moverlo en un solo eje.
- **Arrastra un tirador** para redimensionar. Funciona con todas las formas — rectángulos, elipses, estrellas, polígonos, formas personalizadas, trazados, texto e imágenes.
- **Arrastra el tirador redondo** de encima de la caja para girar.
- **Escape** mientras arrastras cancela el movimiento y lo deja todo como estaba.

El **imán** inteligente se ajusta a bordes, centros, separaciones iguales y guías de las reglas mientras arrastras; las líneas guía muestran las distancias.

La selección es la misma que se ve en el panel [Capas](../objects/layers.md) y se edita en el inspector — todo está sincronizado.

## Con una selección

| Acción | Atajo |
|---|---|
| Borrar | Supr / Retroceso |
| Copiar · Cortar · Pegar | Ctrl+C · Ctrl+X · Ctrl+V |
| Duplicar (se queda en el mismo grupo) | Ctrl+D |
| Empujar | Flechas del teclado |
| Opacidad | 1 … 9, 0 = 100 % |
| Agrupar · Desagrupar | Ctrl+G · Ctrl+Mayús+G |

Haz clic derecho en el lienzo para el menú contextual (ordenar, agrupar, duplicar, borrar…). Ver [Atajos de teclado](../keyboard-shortcuts.md) para la lista completa.
