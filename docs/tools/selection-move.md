# Select

The **Select** tool (**V**) is the default tool for working with objects.

- **Click** an object to select it; click empty space to deselect.
- **Shift+click** adds or removes objects from the selection. Drag on empty space to select with a box.
- **Drag** a selected object to move it. Hold **Shift** to move along one axis.
- **Drag a handle** to resize. Works for every shape — rectangles, ellipses, stars, polygons, custom shapes, paths, text and images.
- **Drag the round handle** above the box to rotate.
- **Escape** while dragging cancels the move and puts everything back.

The smart **magnet** snaps to edges, centres, equal spacing and ruler guides while you drag; the guide lines show the distances.

The selection is the same one shown in the [Layers](../objects/layers.md) panel and edited in the inspector — all stay in sync.

## With a selection

| Action | Shortcut |
|---|---|
| Delete | Delete / Backspace |
| Copy · Cut · Paste | Ctrl+C · Ctrl+X · Ctrl+V |
| Duplicate (stays in the same group) | Ctrl+D |
| Nudge | Arrow keys |
| Opacity | 1 … 9, 0 = 100 % |
| Group · Ungroup | Ctrl+G · Ctrl+Shift+G |

Right-click on the canvas for the context menu (arrange, group, duplicate, delete…). See [Keyboard Shortcuts](../keyboard-shortcuts.md) for the full list.
