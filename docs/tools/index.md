# Tools Overview

The same tools exist in all three interfaces — in Modern they're in the bottom bar, in Pro in the left column, in Smart in the side column of the Layers panel.

| Tool | Key | Purpose |
|---|---|---|
| [Select](selection-move.md) | **V** | Select, move, resize and rotate objects |
| [Node edit](pen-bezier.md#editing-nodes) | — | Edit the points and handles of a path |
| Artboard | **A** | Create and resize artboards |
| [Shapes](shapes.md) | **R** rectangle · **E** ellipse · **S** star | Rectangles, ellipses, polygons, stars and custom shapes |
| [Pen & Bézier](pen-bezier.md) | **D** (Bézier) | Straight-line paths and precise Bézier curves |
| [Brush](brush.md) | **B** | Freehand vector strokes |
| [Text](text.md) | **T** · **P** (paragraph) | Point text and paragraph (frame) text |
| Image | — | Place an image (PNG, JPEG, WEBP, SVG) on the artboard |

Tools with options (shapes, Bézier, brush, text) show their settings in a panel — in Modern and Pro, inside the right-hand panel.

Panning and zooming work from any tool — see [Hand & Navigation](hand-navigation.md).

New objects go to the **artboard you draw on**; if you draw outside every artboard, they go to the active one.
