# Brush

A freehand vector brush: **click and drag** on the artboard to draw a stroke, release to finish it.

Unlike a raster brush, the stroke isn't a bitmap — Vectopen thins the raw mouse trail (removing redundant points below a distance threshold) and smooths it into a clean curve as you draw, so the result stays a lightweight, editable vector path rather than thousands of raw sample points.

Stroke width and color follow the current brush preset. Quality/smoothing settings adapt automatically to the performance profile Vectopen detected for your machine.
