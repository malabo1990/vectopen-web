# Layers

The **Layers** panel shows every object in your document as a tree that matches what you see on the canvas: the top row is drawn on top. Selecting a row selects the object on the canvas and the other way round.

The panel has three tabs: **Layers**, **Pages** (your artboards) and **Resources**.

## Each row

- An **icon** shows the type: rectangle, ellipse, star, polygon, path, text, image or group.
- **Eye** — show / hide.
- **Lock** — locked objects can't be selected or moved on the canvas.
- **Clip** — turn a group or a text into a clipping mask for what's inside it.
- **Double-click** the name to rename it.

## Organising

- **Drag** rows to reorder them or to move an object into or out of a group, at any depth.
- Objects inside other objects (sub-layers) appear under their parent; click the arrow to expand or collapse.
- Objects outside every artboard are listed under **"Outside artboard"**.
- The buttons above the list: select all, new artboard, delete, duplicate, group (**Ctrl+G**), ungroup (**Ctrl+Shift+G**).
- The right-click menu on the canvas has the same actions plus arrange (bring forward / send back).

## Searching

Type in the search box to filter by name, or use a quick filter:

| Filter | Shows |
|---|---|
| `is:hidden` | hidden objects |
| `is:locked` | locked objects |
| `is:group` | groups and artboards |
| `is:text` | texts |
| `is:image` | images |
| `is:selected` | the current selection |

(The Spanish forms `is:oculto`, `is:bloqueado`, `is:grupo`, `is:texto`, `is:imagen`, `is:seleccionado` work too.)

## Panel settings

Click the **⚙** next to the panel title:

- **Layer view** — **Type icons** (default), **Thumbnails** (a small preview of each object) or **Compact** (thumbnail and the three buttons only, no names).
- Text size, row height and panel opacity.
- Which tab opens first, and the size of resource thumbnails.
- **Reset** returns everything to the defaults.

## Resizing the panel

Drag the panel's edge — the left edge in Smart, the right edge (next to the ruler) in Modern and Pro. The width is remembered separately for each interface.

The counter at the bottom shows how many layers the document has.
