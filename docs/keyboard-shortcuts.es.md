# Atajos de teclado

Estos son los atajos que actualmente están conectados a un comportamiento real en Vectopen.

## Edición

| Acción | Atajo |
|---|---|
| Deshacer | Ctrl+Z |
| Rehacer | Ctrl+Shift+Z |
| Borrar selección | Delete o Backspace |
| Copiar | Ctrl+C |
| Cortar | Ctrl+X |
| Pegar | Ctrl+V |
| Duplicar | Ctrl+D |
| Seleccionar todo | Ctrl+A |

## Vista

| Acción | Atajo |
|---|---|
| Navegar lienzo (pan) | Espacio + arrastre, o clic central + arrastre |
| Zoom in | Ctrl+= |
| Zoom out | Ctrl+- |
| Restablecer zoom al 100% | 5 |
| Zoom bajo el cursor | Rueda del ratón |

## Herramienta de texto

| Acción | Atajo |
|---|---|
| Escalar tamaño de fuente | Ctrl/Cmd + arrastre vertical sobre un bloque de texto |

!!! note "Todavía no es un mapa de teclas configurable"
    Vectopen no expone aún una interfaz de preferencias para reasignar estos atajos — la lista de arriba refleja los valores por defecto de la app.
