# Atajos de teclado

Los atajos por defecto. Los atajos de una sola letra solo funcionan cuando no estás escribiendo en un campo de texto. En macOS, **Ctrl** es **Cmd**.

El **panel de teclado** (botón del teclado abajo a la izquierda en Smart) lista las acciones configurables; busca una, haz clic y pulsa la tecla nueva.

## Herramientas

| Herramienta | Tecla |
|---|---|
| Selección | V |
| Rectángulo | R |
| Elipse | E |
| Estrella | S |
| Bézier | D |
| Pincel | B |
| Texto | T |
| Texto de párrafo | P |
| Mesa de trabajo | A |
| Mano (desplazar) | W |

## Archivo y edición

| Acción | Atajo |
|---|---|
| Documento nuevo | Ctrl+N |
| Guardar | Ctrl+S |
| Deshacer / Rehacer | Ctrl+Z / Ctrl+Mayús+Z |
| Copiar / Cortar / Pegar | Ctrl+C / Ctrl+X / Ctrl+V |
| Duplicar | Ctrl+D |
| Seleccionar todo | Ctrl+A |
| Borrar | Supr, Retroceso o X |
| Empujar la selección | Flechas |
| Agrupar / Desagrupar | Ctrl+G / Ctrl+Mayús+G |

## Con objetos seleccionados

| Acción | Atajo |
|---|---|
| Opacidad 10 % … 90 % | 1 … 9 |
| Opacidad 100 % | 0 |
| Opacidad exacta (p. ej. 45 %) | Dos cifras seguidas: 4 y luego 5 |
| Mover / Girar / Escalar con el ratón | Mayús+G / Mayús+R / Mayús+S — luego X o Y para bloquear un eje, clic para confirmar, Escape para cancelar |
| Modo degradado en el lienzo | G (V o Escape para salir) |
| Texto más grueso / más fino | Ctrl+Alt+. / Ctrl+Alt+, |
| Cancelar un arrastre en curso | Escape |

## Edición de nodos

| Acción | Atajo |
|---|---|
| Seleccionar todos los puntos | A |
| Borrar puntos | X, Supr o Retroceso |
| Agarrar (mover) puntos | G, luego X / Y para bloquear un eje; Intro o clic confirma, Escape cancela |
| Volver a Selección | Escape |

## Vista

| Acción | Atajo |
|---|---|
| Desplazar | Espacio + arrastrar, arrastrar con el botón central, o la herramienta Mano |
| Zoom | Rueda (bajo el cursor) · Ctrl+= / Ctrl+- |
| Zoom arrastrando | Mantén Z y arrastra |
| Zoom al 100 % | 5 |
| Desplazar un panel | Arrastrar con el botón central sobre el inspector o Capas |

Los atajos siguen funcionando con el ratón encima de un panel, siempre que no estés escribiendo en un campo de texto.
